# 数独練習帳

白黒・装飾を抑えた、自分用の数独練習アプリです。外部ライブラリ、通信、アカウントは不要です。

## GitHub Pagesでの利用

リポジトリ： https://github.com/jankyjanky0920/mypuzzle

GitHubのリポジトリ設定で、Pages → Build and deployment → Source を「Deploy from a branch」、Branch を「main」、フォルダを「/docs」にして保存します。公開先の固定URLはPages設定画面に表示されます。以後はそのURLをブックマークして、同じブラウザから開いてください。

旧HTMLの試用画面やローカルファイルから、公開URLへブラウザ内の保存を自動移行することはできません。以前の画面で「設定 → バックアップを書き出す」、公開版で「設定 → バックアップを読み込む」を使ってください。GitHubへ送るのはアプリのソースと問題データだけで、手書きや練習履歴は送信しません。

## ローカルファイルでの開き方

`sudoku-practice.html` をダウンロードして、パソコンの Chrome / Edge / Safari / Firefox などのブラウザで開いてください。ZIP 内の `dist/index.html` も同じ内容です。

タブレットでは「アナログ」→「ペン」で、盤面に直接書けます。スマートフォン・パソコンでは「デジタル」の数字・候補入力が使えます。画面幅に応じて補助パネルが盤面の下に移動します。

iPad / iPhone の「ファイル」アプリのプレビューでは、HTML内のプログラムが動かない場合があります。タブレット実機のペンの書き味は未検証です。ブラウザで開ける環境で使用してください。Web配信する場合は、その作業の許可を得た後で別途設定する想定です。ローカルファイル版とGitHub Pages版の保存領域は別です。普段の練習は固定の公開URLで開いてください。

## 操作

- デジタル：マスを選んで1〜9を入力。もう一度同じ数字を押すと消せます。
- 候補：「候補」を選ぶと、小さい数字でメモできます。メモとエンジン内の論理候補は独立しています。
- ペン：盤面に直接書きます。字形の認識・自動的な数字入力はしません。
- 消しゴム：線に触れると、そのひと筆を消します。
- 「指では書かない」：ペンで書き、指ではスクロールする設定。オフにすると指でも書けます。
- 戻す・やり直す：数字、候補、手書き、記録などを操作単位で戻せます。履歴は現在開いている間の45操作までです。
- アナログ：手書き・紙で解いて、A〜Dの4数字を提出します。4マスの正解であり、全盤面検証とは区別します。
- ヒント：場所→解法→理由→結論。理由以降は解答の数字を含む場合があります。
- アナログでのヒント：手書きの数字は読み取らないため、必要に応じて「確定数字を転記する」かデジタルモードで確定数字を入力します。
- 記録：解法、対象マス、理由・手順を書き残せます。模範解答は別途明示して開きます。
- 印刷：初期数字とABCDを用紙向けに配置します。手書きの線や入力済みの数字は印刷しません。

キーボード：1〜9＝数字、矢印＝移動、N＝候補、P＝ペン、E＝消しゴム、Delete / Backspace＝削除、Ctrl/⌘+Z＝戻す、Ctrl/⌘+Shift+Z＝やり直す。

## 保存

進捗、手書き、解法記録、ABCD入力、経過時間を同じ端末・同じブラウザのlocalStorageに自動保存します。問題を替えても履歴から戻れます。直前の保存も予備として保持し、本体を読み込めない場合は予備からの復元を試みます。どちらも読み込めない場合は、空のデータで元データを上書きせず保護します。デジタルとアナログの完了判定は独立しています。

設定からJSONバックアップの書き出し・読み込みができます。ブラウザのデータ消去、プライベートブラウズ、保存容量不足、ローカルファイルの開き方の変更などに備えて、必要な記録はバックアップしてください。保存に失敗した場合は画面に表示します。自動同期はありません。

## 収録内容

初版は **検証済み12問（通常8問、最上難易度4問）** を収録しています。「新しい問題」はこの集合から未着手の問題を選び、一巡後は再挑戦を明示します。ブラウザで無検証の問題を即時生成しません。追加問題を作る生成器はソースに含まれています。

- 全問題で、厳密探索が完了し、解が1つだけであることを確認。
- 完成解を受け取らない論理解法エンジンで完答。
- 手順ごとの構造証明を、解法発見処理とは別の検証関数で確認。
- 通常は基本解法とX-Wingまで。最上難易度は通常解法だけでは止まり、上位解法で完答。
- AIC / XY-Chainは最大7リンク。仮置き分岐、Forcing Net、一意性前提の解法は不使用。
- ABCDは基準解答の最後の4マス。12通りの順序検査で各マスが初期空欄の80%以上を埋めた時点以降に確定。3通りの目標優先検査でも4マスが揃うまでに80%以上の確定が必要。
- 12通りは、標準順、逆順、同等の選択肢への周期的な寄り道10通りです。すべての人間の解答順を網羅する検証ではありません。
- 各手の前提となる候補消去・数字確定を追跡し、手順の依存関係を保存。収録問題の最長依存連鎖は21〜35手。

「最上難易度」はこのアプリ内の解法基準です。世の中のすべての数独に対する絶対的な難しさを意味しません。使用可能解法の探索には上限があるため、「今使える解法」はすべてを列挙する保証ではありません。

## 開発用ファイル

- `src/index.html`：画面構造
- `src/style.css`：白黒の画面・レスポンシブ・印刷スタイル
- `src/app.js`：入力、ペン、保存、判定、記録
- `src/storage.js`：前回の保存への復旧、読み込み不能データの保護
- `docs/index.html`：GitHub Pagesで公開するビルド済みHTML
- `docs/.nojekyll`：そのまま静的配信する指定
- `src/engine.js`：候補管理、解法、証明検証、一意解検証、作問
- `src/puzzles.json`：問題、完成解、証明付き手順、依存関係、ABCD検査結果
- `scripts/generate-pool.js`：品質条件を通る問題だけを収録する生成器
- `scripts/build.js`：依存のない単一HTMLを作るビルダー
- `tests/engine.test.js`：生成・一意性・証明・難易度・ABCDの回帰検査
- `tests/storage.test.js`：再読込、予備への復旧、容量不足、読み込み不能時の保護
- `VALIDATION.md`：検証結果と未検証範囲

Node.js 20以降で、追加のインストールなしで実行できます。

```sh
npm test
npm run build
```

問題数を増やす例（macOS / Linux）：

```sh
COUNT=30 SEED=30000 npm run generate
npm test
npm run build
```

生成は時間がかかります。最大試行回数で指定数に達しなければ終了コード1になり、合格した問題だけが残ります。検査条件を緩めて未検証の問題を混ぜる処理はありません。

配布HTMLには判定に必要な完成解を含みます。自分用の練習アプリであり、不正閲覧を防ぐ試験システムではありません。
